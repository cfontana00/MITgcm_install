Install and compile MITgcm coupled to BFM on ECMWF Atos cluster.


1/ MODEL COMPILATION
Set the configuration directory name "NAME" in install.sh and run :

$./install.sh

The model is compiled in $HOME/$NAME

2/ CHAIN SETUP

Set the configuration directory name "NAME" in install.sh and run :
$./install_chain.sh

# Enjoy
